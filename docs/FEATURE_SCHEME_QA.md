## 1. 检测框特征 vs 动作特征：不是二选一，是分工互补

概念厘清：所有特征都来自检测框，但框内信息分两类——**静态几何**（位置/坐标/面积）
与**动态运动**（速度/距离变化/轨迹/插值状态）。实验证据：

| 特征 | 信息倾向 | 强项指标（val 单独） | 说明 |
|---|---|---|---|
| v2（动态通道多：speed×每类、pair 距离变化、缺失插值状态） | 运动/动态 | F1@0.25 **24.00** 最高 | 边界定位强 |
| v3（轴系坐标为主，归一化掉幅度） | 静态几何 | edit **31.07** 最高 | 段识别与排序强 |
| v2⊕v3 拼接（226 维） | 两者兼备 | 三项全第一（33.85/34.62/27.03） | 双赢 = 互补实证 |

**结论**：静态几何回答"这是哪个动作段"，动态运动回答"段边界在哪一刻"。
单独比较时边界定位（部署痛点）更依赖动态通道；合并使用才最优。
另外纯外观路线（ImageNet CNN 像素特征，S2/S3）已被证伪——14 视频数据量下，
检测框几何+动态全面优于像素外观（域差距 + PCA 仅保留 15.6% 方差）。

## 2. 维数的具体计算（总维数 = 各块宽度之和）

通道定义：8 通道 = present / conf / 坐标×2 / 面积比 / speed / missing_age / imputed。

| 方案 | 计算式 | 维度 |
|---|---|---:|
| bbox-40 | 8 类 × 5 通道（presence,cx,cy,w,h） | 40 |
| roi-144 | 8 类 × 6 区域(2×3 网格) × 3 通道(presence,count,max_area) | 144 |
| v2 / v3 | hand_count(1) + hand 双 slot×8(16) + 8 非 hand 类×(count+8)=8×9(72) + pair 7 组×3(21) + 时间(3) | 113 |
| v2⊕v3 | 113 + 113 直接拼接 | 226 |
| **v4** | hand_count(1) + hand×2×8(16) + ctrl(count+6)(7) + mid(count+8)(9) + 事件类 3×(count+4)(15) + pair 3 组×3(9) + 时间(3) | **60** |

v4 从 113 砍到 60 的精确账目：
剔 3 类（distal presence 8% / short_brush 2% / long_brush **恒零死块**）−27、
ctrl 砍 along/across（轴端点坐标恒 0）−2、事件类砍 conf/speed/missing/imputed −12、
pair 7→3 组（原 7 组全部以废弃/恒零类为端点）−12。逐列清单与三条复核路径见
`FEATURE_V4_DIM_SPEC.md`。

## 3. test split 指标的评价方法

### 3.1 指标含义

| 指标 | 衡量什么 | 解读 |
|---|---|---|
| edit score | 段序列编辑距离相似度（0~100） | 切出的段落序列（识别+排序+数量）与真值像不像 |
| F1@0.25 | 段级匹配 F1（IoU≥0.25） | v4 的 30.61 = 30.6% 的段匹配对在重叠率 ≥25% 下成立——边界大致对的命中水平 |
| F1@0.5 | 同上但 IoU≥0.5 | 边界精确对齐——当前全场个位数，是最大短板 |
| frame mIoU | 帧级逐类 IoU 平均 | 帧级微观判别（bbox-40 最强 20.37 但段级最弱之一） |

IoU 阈值梯度：0.1 宽松（大致命中）/ 0.25 中等（边界大致对）/ 0.5 严格（边界精确）。

### 3.2 test 口径的四个注意（评价时必须带上）

1. **跨批次**：test 来自 project-18，train/val 来自 project-16——val 33.85 与 test 25.72
   不是"下降"，是不同分布的两次测量；**绝对值不可互比，只看同口径内的相对排序**；
2. 样本小：8 视频 2639 帧，seed 方差大（v4 三个 seed 的 F1@0.25 从 23.66 到 31.58）；
3. 构成偏斜：长短毛刷专项数据，类分布与 train 不同（正好是目标场景）；
4. 正确用法：**val 看同分布绝对性能，test 看泛化排序**——v4 的 test F1@0.25 领先
   v2⊕v3 达 4.5 点，这是"废弃通道 = 过拟合源"结论的依据。

## 4. 未来方向（按优先级）

| 优先级 | 方向 | 理由与预期 |
|---|---|---|
| **P0** | v2'⊕v3' 消融（~170 维，~25 分钟） | 分离"信息量损失"与"过拟合源剔除"：若 val 回 33+ 且 test 保 30+ 即最终答案 |
| **P0** | GPU 多 seed 正式复跑 | 全部结论目前为 CPU exploratory 口径，定版必经 |
| **P1** | **数据侧扩量**（收益最大） | 14 训练视频是主瓶颈（loss 曲线证明 ep2~5 即过拟合）；action-test 扩采集、water_injection 补数据（val 仅 17 帧）、val 扩充或 LOVO |
| **P1** | 模型侧：窗口 16→32/64、段级平滑后处理 | 上下文是已证瓶颈：MS-TCN 双向 39.81 > GRU 31.07；加长窗口是最便宜干预 |
| P2 | 指标扩展：idle-excluded macro、insert↔withdraw 互混率入 summary | 当前 macro 被 68% idle 失真；互混是 P0 对比对 |
| P2 | 检测器升级（可选） | distal(8%)/short_brush(2%) 检测质量差是根因——重训 YOLO 提升后可 revisit 废弃决策 |
| P3 | 手部关键点（MediaPipe）替代 hand box | 手部线的正确重启方式（box 区域统计已被证不足以翻案） |
| P3 | 域内微调 CNN | 通用 ImageNet 特征失败 ≠ 外观无用，域内微调是另一回事 |

**一句话**：近期收尾特征定版（消融 + GPU 复跑），中期主攻数据量与模型上下文，
远期看新特征形态（关键点 / 域内 CNN）。
