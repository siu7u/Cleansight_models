# 实验报告：特征提取方式与精度杠杆（MS-TCN 时序线）· 13 个杠杆 × 多 seed

- 日期：2026-09-23
- 目的：回答两个问题——**① 换不同的特征提取方式（契约 / 通道 / 增强）能不能提升指标；
  ② 除特征外还有哪些能提精度的手段、各自值多少、代价是什么。** 所有结论都给出配对检验
  （逐 (seed,视频)×类 Wilcoxon）与判读等级。
- 一句话结论：**13 个杠杆里只有 4 条被验证有效**——换架构（`mstcn2`）、加宽到 h128、用满
  `roi-grid-144` 契约、以及**换选点口径 `best_metric=val_edit`**；其余 9 条的正确做法是
  **保持默认或直接不用**——其中 T-MSE 权重 / dropout 改动本身**有害**（改了更差），
  序列去均值 / 活动量 clip / 目标随机遮罩 / presence-only 契约 / 多种子集成 / 更深 / h256+
  **无效或只买召回**。**换特征提取方式这条轴已探尽：没有任何替代契约能超过 roi-144。**
- 规模：**新增 122 个 run / 128 份正式评估**（另复用容量研究的既有批次作对照）；全部 CPU 训练。
- 与既有报告的关系：容量轴见 `EXPERIMENT_REPORT_MSTCN_CAPACITY_20260922.md`；本报告的逐轮机制、
  口径讨论与全部原始数字见 `FEATURE_STRATEGY_COMPARE.md` 第十三~二十七轮。

## 1. 实验设置

| 项 | 值 |
|---|---|
| 数据 | `datasets/cleansight-ActionMixed-auto-lhh`；test 8 视频 / 2,639 帧（每 4 帧采样 1，≈7.5 fps）；revision `6375eba95c28…` |
| 特征契约 | 主：`temporal.actionmixed-auto-roi-v1`（roi-grid-144 + z-score）；对照：`-v3`(bbox-40)、`-roi-v2`(96)、`-hand-v1`(40)、`-global-hand-v1`(80)、**新增 `-roi-presence-v1`(48)** |
| 统一配方 | lr 5e-4、60 轮、`patience=null`、wd 1e-4、`best_metric=val_f1_0.5`（选点实验除外） |
| 流水线 | `mstcn`/`mstcn2`/`transformer` = 离线全序列（**逐帧 argmax、无平滑**）；`gru` = 因果滑窗（`causal_decision` 平滑，md 可调） |
| 统计 | 逐 (seed,视频)×类配对 Wilcoxon（零差值对剔除，n<6 报样本不足）；**一律同 seed 配对**，机构位数仅作参考 |
| 强制读数 | 任何结论必须同时报 **非 idle 帧数**与**段数比**（防"靠压掉非 idle 换 edit"的假增益） |

## 2. 结果

### 2.1 主结果：杠杆定版表

| # | 杠杆 | 定版设置 | 效果（配对中位差 / 胜-负 / p） | 判读 |
|---|---|---|---|---|
| 1 | 架构族 | **`mstcn2`** | GRU(md=5) 相对它 edit **−15.14 / 8-14 / p=0.0348**；Transformer **−24.24 / 5-18 / p=0.0062** | 有效 |
| 2 | 宽度 | **h128** | h64→h128 **+16.67 / 17-2 / p=0.0003**；h32→h128 **+18.38 / 15-6 / p=0.0142** | 有效 |
| 3 | 特征契约 | **roi-grid-144** | 替代契约 insert 召回 −11.9 ~ **−32.4**（p=0.0002~0.094）；96 维重排版 edit −18.80 p=0.0177 | 有效（保持） |
| 4 | **选点口径** | **`best_metric=val_edit`** | edit **+9.63 / 29-13 / p=0.0107**；insert 召回 **+5.46 / 18-5 / p=0.0214**（8 seed） | **有效（本次新增）** |
| 5 | T-MSE 权重 | 保持 0.15 | 消融（w=0）h128 上 F1@0.1 **−6.93 / 5-15 / p=0.0192** | 保持默认 |
| 6 | 序列归一化 | 保持 `none` | `demean` insert +29.7pp（13-0，p=0.0002）但 acc −11pp、段级不显著 | 不采用 |
| 7 | 活动量 `class_weight_clip` | 保持 0.1 | 0.03：insert +19.43 / 24-10 / p=0.0101，但 acc/fp 变差、段级不显著 | 不采用 |
| 8 | dropout | **保持 0.3** | 0.2 在旗舰上 F1@0.25 **−9.52 / 6-15 / p=0.0384**、insert −14.29 / 1-8 / p=0.0273 | 不用 |
| 9 | 更深（stage/层数加倍） | — | edit +5.56（p=0.3776）、insert −11~−20pp | 不用 |
| 10 | h256 以上加宽 | — | s4l10：F1@0.1 −5.14 p=0.0401、F1@0.25 −12.16 p=0.0025 | 不用 |
| 11 | 离线后处理平滑 | — | val 选参后 edit 45.30 → 33.33（test 选参会造出 +22 分假增益） | 不用 |
| 12 | 目标随机遮罩增强 | — | insert precision **−21.46 / 3-10 / p=0.0398**；全类遮罩 acc −7.7pp | 不用 |
| 13 | **多种子集成**（逐帧多数投票） | — | 最好 k=8 也只打平（edit −0.85 p=0.81）；k=2/4 明显更差（−6.74 / −1.29） | 不用 |

**当前最佳配方**（8 seed 实测）：
```
mstcn2 s4l10 h128（331 万参） + roi-grid-144(z-score)
lr 5e-4 / 60 轮 / patience=null / dropout 0.3 / T-MSE 0.15 / clip 0.1（全部默认）
best_metric = val_edit
```
→ **edit 中位 51.08**（默认选点 49.13）、F1@0.1 40.01、F1@0.25 31.61、acc 53.98、段数比 0.90、非 idle 692.5。

### 2.2 特征契约对照（mstcn2 s2l5，两档宽度各 3 seed；差值 = 该契约 − roi-144）

| 契约 | dim | edit（h128） | F1@0.1（h128） | F1@0.25（h128） | **insert 召回（h128 / h32）** |
|---|---:|---:|---|---|---|
| **roi-144（基准）** | 144 | **46.45** | **41.29** | **33.59** | 基准 |
| bbox-40 | 40 | −14.29（p=0.16） | **−10.00（p=0.0032）** | −11.67（p=0.15） | −11.93（p=0.094）/ **−22.95（p=0.0352）** |
| bbox-40-hand | 40 | +8.33（p=0.63） | +1.59（p=0.52） | −0.12（p=0.49） | **−28.15（p=0.0006）** / **−22.95（p=0.0273）** |
| roi-96-v2（可见性重排） | 96 | **−18.80（p=0.0177）** | **−5.00（p=0.0263）** | −10.26（p=0.32） | **−32.43（p=0.0002，0/13）** |
| bbox-80-global-hand | 80 | −10.07（p=0.24） | −5.56（p=0.32） | −4.79（p=0.73） | −17.20（p=0.068） / **−22.95（p=0.0488）** |
| **presence-48（本次新增）** | 48 | −12.91（p=0.14） | **−7.04（p=0.0329）** | −9.97（p=0.41） | −6.66（p=0.90） |

- **h128 上没有任何替代契约提高段级指标**；`roi-96-v2` 反而显著更差。
- **roi-144 唯一稳健的优势是 `insert` 召回**（8 个对比里 6 个显著更差）。
- **"段级中位数更高"会误导**：`bbox-40-hand` 的 edit 中位（51.05）高于 roi-144（46.45），但配对不显著，
  且 acc 低 7pp、insert 显著更差。
- 通道语义上三通道高度冗余（`presence~count` 平均 |r|=0.990、`~max_area` 0.926），
  **insert / sbc 的判别信号集中在 presence 平面**（LDA 探针下 insert 41.3→68.8、sbc 16.7→73.0）——
  这解释了 roi-144 独有的 insert 优势，但**把契约砍成 presence-only 后训练反而更差**（上表末行）。

### 2.3 架构族与容量（统一配方，3~8 seed）

| 臂 | 流水线 | edit | F1@0.1 | F1@0.25 | 逐 seed 摆幅 |
|---|---|---:|---:|---:|---:|
| **mstcn2 s4l10 h128** | 离线 | **51.47** | **44.78** | **35.82** | **0.64** |
| mstcn2 s2l5 h128（d0.2） | 离线 | 49.03 | 38.66 | 21.85 | — |
| mstcn2 s2l5 h128（d0.3） | 离线 | 46.45 | 41.29 | 33.59 | — |
| mstcn h128 | 离线 | 41.79 | 26.98 | 21.40 | — |
| GRU（md=1 / md=5） | 因果 | 42.40 / 40.89 | 38.66 / 37.04 | 22.73 / 22.22 | **14.5** |
| Transformer（d64×2） | 离线 | 27.31 | 23.79 | 18.59 | 8.0 |

- 排序 **`mstcn2` >（`mstcn` ≈ GRU）> Transformer**；这**修正了**第十二轮"GRU > MS-TCN > Transformer"
  ——那条用的是旧配方（lr 2e-3/20 轮）且当时没有 `mstcn2`。
- GRU 是"保守型"：非 idle 预测仅 354~376 帧（mstcn2 为 671~778），**flush 完全不预测（F1=0）**、
  insert 召回只有 mstcn2 的 1/3；且**逐 seed 摆幅 14.5 vs mstcn2 的 0.64**。

### 2.4 选点口径（本次新增的免费杠杆）

同一配方、只换 `best_metric`（两臂各 8 seed）：

| 选点口径 | edit | F1@0.1 | F1@0.25 | acc |
|---|---:|---:|---:|---:|
| `val_f1_0.5`（现行默认） | 49.13 | 38.69 | **32.84** | **54.64** |
| **`val_edit`** | **51.08** | **40.01** | 31.61 | 53.98 |
| `val_f1_0.25`（3 seed 对照） | 46.97 | 39.68 | 31.75 | 53.66 |

- **`val_edit` 让 edit +9.63（p=0.0107）、insert 召回 +5.46（p=0.0214）**；逐 seed **6/8 提升**（中位 Δ +4.42）。
- **326 个 run 上的迁移体检**：现行默认 `val_f1_0.5` 与 test 的 Spearman ρ 仅 **0.199**（选点近乎随机），
  `val_f1_0.1`(0.623)/`val_f1_0.25`(0.559) 更好；`val_acc` 的 val−test 差 +14.76 且峰值常在第 1 轮；
  `val_loss` 的最小值几乎恒在第 3~9 轮——**都不能用于选点**。
- 提醒：**3 seed 读数 58.35 偏乐观**（原 3 个 seed 恰好都在 51 附近），8 seed 才是可信幅度。

| 原结论 | 本次修正 |

## 4. 诊断与观察

1. **精度天花板已经定位（不是模型/特征/损失的问题）**：当前最强模型上 **51.6% 的真值段连标签都认错**
   （flush 20/21、withdraw 25/27、sbc 18/18）；IoU@0.5 的 193 个漏检里 113 个（59%）属"标签错"。
2. **错误的大头远离标签边界**：距最近标签切换 ≤3 帧的帧占 16.1%，只承载 **21.9%** 的错误；
   **78% 的错误发生在段内部**（整段认错），且该类错误对容量/架构/损失/增强**均不敏感**。
3. **加宽买到的是"时序结构"而非"逐帧更准"**：同架构 h32→h128 的 edit +18.38（p=0.0142），
   但 acc 中位持平（53.73 vs 53.66）、池化帧错误率甚至略差。
4. **`edit` 不是边界指标**（实测）：把真值 `idle(20) flush(10) idle(20)` 预测成 `idle(38) flush(1) idle(11)`
   （时长全错、顺序对）→ **edit = 100.0**；预测多出一个 `insert` 段时 acc 98% 而 **edit = 60.0**。
   → 报 edit 必须同时报段数比与非 idle 帧。
5. **多种子集成失效的机制**：不同 seed 的段边界不同，逐帧投票在分歧处反复翻转 → **段被打碎**，
   而 edit 对"多出段"重罚，于是共识预测比任何单个成员都差（投票后加最小时长合并也只修复一部分）。
6. **四次"小配置有效、大配置有害"**：T-MSE 权重、活动量 clip、T-MSE 在 h32 vs h128、dropout 0.2
   → **任何旋钮都不应跨容量外推**（这也是本项目最重要的一条方法论）。

## 5. 结论与遗留

### 结论（分级）

| 结论 | 等级 | 证据 |
|---|---|---|
| 换架构到 `mstcn2` 是本线最大的精度改进 | 可判读 | GRU −15.14 p=0.0348；Transformer −24.24 p=0.0062 |
| 加宽到 h128 有效、h256 有害 | 可判读 | h64→h128 p=0.0003；h256 F1@0.25 −12.16 p=0.0025 |
| `roi-grid-144` 仍是最优特征契约，且"更省的契约"不成立 | 可判读 | 5 个替代契约 insert −11.9~−32.4；presence-48 的 F1@0.1 −7.04 p=0.0329 |
| **选点口径 `val_edit` 有效（免费杠杆）** | 可判读 | 8 seed：edit +9.63 p=0.0107、insert +5.46 p=0.0214 |
| 后处理平滑 / 随机遮罩 / 多种子集成 / 更深 / h256+ / dropout 0.2 | 可判读（无效或有害） | 见 §2.1 第 8~13 行 |
| 段级指标的天花板由数据与标注决定 | 可判读 | 51.6% 段标签错；78% 错误远离边界且对各旋钮不敏感 |
| 检测侧扩召回救 `sbc` | **不可判读（阻塞）** | 数据无像素源，无法重跑检测 |

### 遗留（未做，含原因）

1. **检测侧扩召回**（唯一能救 `sbc` 的路径）：`datasets/cleansight-ActionMixed-auto-lhh/frames/`
   **只有 bbox txt、没有图像**，无法重跑检测；需先补像素源（下载 project-16 视频抽帧，或采集时保留帧图）。
2. **标签时间轴人工审计**（`flush` / `withdraw`）：需人工看视频核对；工具已备
   （`tools/probe_boundary_error.py` 给出逐段"标签错/边界错"分解）。
3. **GRU / Transformer 的容量梯度**：架构族排序已定，容量轴在 `mstcn`/`mstcn2` 上已饱和 → 优先级低。
4. **分类（ROI）真实数据链路**：其评估仍是 in-sample（缓存由 train+val 构建），需给 test split 单独建缓存
   —— 属另一条流水线，不在本报告范围。
