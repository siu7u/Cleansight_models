# 后处理 v2 方案：滤波-解码一体化（2026-10-17）

## 一、当前方案的缺陷

现行最优（k=5 均值平滑 + min/max 合并，LOVO edit 69.23）有两个结构性问题：

| 缺陷 | 机理 | 证据 |
|---|---|---|
| **均值平滑模糊边界** | 两类概率在边界附近 ~50/50，均值后两边都压低，argmax 抖动反而加剧 | 边界 P90 误差 97 帧 |
| **贪心合并级联** | "短段并入更长邻居"逐对进行：idle 吸收短段后更长→更易吸收下一段→雪崩 | fold13 全灭案例（7 动作段→0，帧acc 58%→34%） |

## 二、三类候选方法

### B 中值滤波（替代均值）
原理：中值对阶跃边界零模糊（窗口内只要边界一侧占多，输出就是那一侧）。
去噪机理：孤立的 1-2 帧误判在中值下被直接消灭（不是被平均稀释）。
参数：k ∈ {3,5,7,9}；可与滞回/Viterbi 叠加。

### C 滞回切换（置信门控）
原理：切换到新类需要 conf > θ_hi（强证据），维持当前类不需要门槛。
抗抖动机理：边界处的低置信抖动（conf 0.4-0.5 的反复横跳）全部被压制。
参数：θ_hi ∈ {0.4,0.5,0.6,0.7}；θ_lo 留作扩展（双阈值强化版）。

### D Viterbi 全局解码（去噪+合并且一体）
原理：求整条序列的全局最优路径——发射代价 -log P(c|t) + 转移代价（换类罚）。
关键优势：**不需要 min/max 后处理**。短碎段的"换类两次的转移代价"天然超过它省下的发射代价，
全局最优自动消灭碎段；真实长段不会像贪心合并那样被级联吞掉。
参数：switch_cost ∈ {0.3,0.5,1.0,1.5,2.0,3.0}。

### D+ 类条件转移代价（领域先验）
真实工作流中 idle↔action 是常见转移，lbi→lbw 是固定工序顺序，其余 action↔action 罕见：

| 转移 | 代价 |
|---|---|
| 停留（不切换） | -stay_bonus（奖励） |
| idle↔action | low（0.5） |
| lbi→lbw / lbw→lbi | low（0.5） |
| 其余 action↔action | high（2.0） |

## 三、验证协议（吸取 §19/§21 教训）

1. **LOVO 35 折 edit 中位为准**——test 8 视频只作参考展示；
2. **案例回归**：fold13（级联全灭案例）与 fold07（最难折）单独检查——新方法必须不复发级联；

4. 胜出配置需在 **raw 未经平滑的概率** 上重验一次（确认增益来自方法而非平滑叠加）。

## 四、判定标准

- 主指标：LOVO edit 中位 > 69.23 即为改进；
- 副指标：F1@0.25 中位不降（>52.78）；
- 约束：fold13 的动作段存活数 > 0（防级联复发）。

## 六、初筛结果（10-17 凌晨已跑完）

| 方法 | 最佳配置 | LOVO edit 中位 | vs A1 |
|---|---|---:|---:|
| A1 baseline | mean-k5 + min/max | 69.23 | — |
| B 中值滤波 | k=7 | 69.23（持平，k3/k5 略低） | 0 |
| **C 滞回切换** | **hi=0.6** | **72.50（+3.27）** 🔥 | **+3.27** |
| D Viterbi | s=2.0/3.0 | 62.50 | -6.7 |

**关键信号**：滞回 hi=0.6 的 edit +3.27 是初筛唯一改进——但 F1@0.25 掉到 45.45（-7.3），
说明滞回压制切换同时伤到了真实短段。精扫需在 0.5-0.6 之间细化并测试与中值/类条件转移的组合。
Viterbi 全面低于 min/max 方案（s 增大到 3 仍差 6.7）——一阶转移代价对段长分布的表达力不足，
类条件转移（D+）与 stay_bonus 变体是明天的重点。
