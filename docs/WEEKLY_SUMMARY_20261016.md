## 一、数据集 v4.1（10-08 发布）

**发现 Label Studio 标注时间轴 24fps vs 视频 30fps 的系统性偏差**（证据：14/37 标注任务上限精确贴住时长×24）。
全部标签 ×1.25 重标定 + 15fps 重采样 + 18 个新视频。

**重训结果**：test edit 34.85 → **56.46（+21.6）**，LOVO 中位 39.29 → 47.83。

**改写的结论**：withdraw F1 0.076→0.591（7.8 倍）——原 P0【数据稀缺】证伪，根因是标签漂移。

## 三、错误归因（10-14，含重大修正）

**初版结论被推翻**：原判"81% 错误来自 YOLO 5 个不可见检测类"——严格对照（错误帧 vs 正确帧的检测细节）显示 **hand 检测在错误帧基本正常**。

**修正后的真实归因**：

| 根因        | 证据                                  |
| --------- | ----------------------------------- |
| 过渡帧标签模糊   | lbi→lbw 混淆帧速度 0.045 恰好介于两动作典型值之间    |
| 画面边缘出画    | lbi→flush 混淆帧 hand_cy=0.183（手大部分出画） |
| 非典型速度     | miss_lbi 速度 +42%、miss_sbc 速度 2×     |
| sbc 工具不可见 | short_brush 检出率 0%（唯一保留的 YOLO 强归因）  |

## 四、后处理优化（10-14）：本轮最大单项提升

**min_len 过保守是根因**——P10 先验把大量真实的短动作段误并为 idle。

| 配置                    |      LOVO edit 中位 |
| --------------------- | ----------------: |
| P10 基线                |             56.25 |
| **动作类 ×0.2 + 平滑 k=5** | **69.23（+12.98）** |

另：idle 惩罚为否定结论（-8.4 edit）；GRU×5 ensemble 的 F1@0.25 +1.3；TCN 混合 ensemble 全面失败。
