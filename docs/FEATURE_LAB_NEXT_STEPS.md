## 2. 当前最优方案

**特征选型：`clean_bbox_v3_scope_frame`（113 维，scope 器械轴相对坐标系）+ GRU 滑窗**

| 项 | 内容 |
|---|---|
| 特征构造 | 以 `scope_control_body → scope_distal_end` 定义器械轴；位置编码为沿轴/垂轴分量（÷轴长）；面积编码为相对 distal 面积的对数比；轴丢失多级回退（distal-mid → mid-control → 上一帧有效值 → (1,0)），`ref_len/ref_area` 前向填充 |
| 维度布局 | 113 = hand_count + hand×2 + 8 目标×9 + 7 pair×3 + 时间 3（块结构与 v2 一一对应） |
| 模型配方 | GRU hidden=128 ×3 层；wd=1e-4 / dropout=0.2 / patience=4 / best_metric=val_f1_0.5 |
| 成绩（3-seed 中位数） | **edit 31.07 / F1@0.1 25.93 / F1@0.25 18.52**；逐 seed 26.98 / 31.07 / 31.41，全部高于 roi-144 中位数 |
| 部署属性 | 因果、无状态、逐帧、纯几何——零额外模型依赖，成本与 roi-144 同级 |
| 验证链 | MS-TCN 探针（v3 39.81 ≫ v2 29.23，坐标非平稳假设证实）→ GRU 正面（31.07 > roi 24.83），判据"同时优于 B0a/B0b"通过 |
| 状态 | **CPU exploratory 定版候选**；升正式需 GPU 复跑背书 |

淘汰路径备忘（3-seed 中位数 edit）：bbox-40（18.53）< global-hand-80（17.06）< hand-40（15.81）
均未过判据；S2 通用 CNN（16.01）域差距失败；S3（edit 25.22 但 F1@0.25 仅 12.50）边界精度不足。

## 3. 准确率低的原因分析（按证据强度分层）

### 3.1 数据层（主因）

1. **训练量严重不足**：14 视频 / 9575 帧。loss 曲线直接证明——val_loss 在 epoch 2~5 见底
   回升（FEATURE_LAB §6.2.1），模型几个 epoch 就记住了训练集，泛化无从谈起；
2. **类别极度失衡**：idle 占 train 65.52% / val 68.20%；water_injection 仅 194 / 17 帧
   （0.50%）——稀有类在交叉熵下被忽略，全零命中是必然；
3. **val 集只有 4 个视频**：单视频分布偏移即可主导指标（seed 间 edit ±7 波动的根源），
   当前数字的置信区间本身就很宽；
4. **特征源头质量**：特征全部来自 YOLO 自动检测框，检测误差原样传导；auto 通道只覆盖
   6 个检测类（**short_brush / brush_tip_out 恒为零**，这两个类等于"看不见"）；标注五列
   无真实置信度（默认 1.0 填充，exploratory 口径）；
5. **动作边界标注模糊**：插入/撤出是渐变过程，人工边界本身有分歧；7.5fps 采样下
   短动作仅剩几帧。

### 3.2 特征层

6. **纯几何丢外观**：器械是否接触镜面、水流是否可见等判别性视觉线索不在 bbox 里；
   S2 的 ImageNet CNN 失败只说明**通用**外观特征不行，不代表外观信息本身没用
   （域内微调是另一回事）；
7. **关键帧特征缺失**：scope 类在手部区域 presence 仅 14~16%（遮挡/出画），
   动作发生瞬间的特征可能正好缺失。

### 3.3 模型层

8. **滑窗上下文太短**：window=16 ≈ 2 秒，insert→withdraw 的判别需要更长时序依赖——
   MS-TCN 双向拿到 39.81 vs GRU 31.07，差距本身说明**上下文利用是可改进瓶颈**；
9. **帧级独立监督**：末帧监督 + 无段级结构约束（无 HMM/CRF 式平滑），帧级抖动直接
   传导到段边界——评估中 start_mae 高达 343 帧即段起点定位差的直接体现。

### 3.4 一句话归因

**主因是数据（量少 + 失衡 + val 太小），次因是时序建模（窗口短 + 无段结构），
特征方案已接近"纯几何"的上限**——v3 相对 bbox-40 的 +12.5 edit 就是特征侧的改进空间；
要从 31 冲到 60+，大概率需要数据与模型侧发力。

### 3.5 对应的改进方向

| 层 | 方向 | 对应上文 |
|---|---|---|
| 数据 | 采集 action-test 专项数据、补稀有类、扩 val | §1.3、§3.1 |
