### 2.2 类别不均衡与覆盖

- idle 占 54%——但 edit 指标天然对 idle 灌水免疫（段级 LCS）；
- **flush 和 sb_clean 是薄弱类**：帧数少（<5k）且覆盖视频少（17/43）——
  test 中 sb_clean 仅 2 个视频 127 帧，评估方差大；
- lb_insert/lb_withdraw 信息量最足（长动作、覆盖广），是 C7 角色化方案的主要收益对象。

## 三、最新后处理方案（v1.2，2026-10-17 定版）

### 3.1 流程

```
逐帧概率 [T, 6]
  → ① 概率平滑：逐类通道均值滑动窗 k=5
  → ② argmax
  → ③ min 合并：短于 min_len[c] 的段并入邻居（idle 优先）
  → ④ max 拆分：超过 max_len[c] 的段在阈值截断
  → 动作段序列
```

### 3.2 定版参数

| 类 | min_len（帧） | max_len（帧） |
|---|---:|---:|
| idle | 11 | 288 |
| water | 1 | 3 |
| flush | 3 | 89 |
| lb_insert | **28** | 232 |
| lb_withdraw | **10** | 92 |
| sb_clean | **6** | 131 |

- min_len = 逐类时长先验（P10 × 0.2 定标 + 逐类微调），max_len = P95 原值
- idle 优先合并消除级联吞噬（fold13 案例）
- 统一值代替逐类会 -6.7 edit（消融已证，不可简化）

### 3.3 效果与版本演进

| 版本 | LOVO edit 中位 | 增量 | 关键改动 |
|---|---:|---:|---|
| v1（P10 基线） | 56.25 | — | 一刀切 min |
| v1.1（×0.2 + k5） | 69.23 | +13.0 | 动作类 min 整体放宽 |
| **v1.2（逐类 + idle 优先）** | **71.43** | **+2.2** | 逐类精调 + 合并方向修正 |
| **累计** | | **+15.2** | |

### 3.4 因果（流式）版

尾随平滑替代中心窗 + 90 帧定案缓冲（6s 延迟）——**质量零损失**（LOVO 中位完全一致），
流式配方完备。

### 3.5 已否定的替代方案（均为全量扫描结论）

| 方案 | 结果 | 依据 |
|---|---|---|
| Viterbi 全局解码（含类条件转移） | -6.7 | 一阶转移表达不了段长先验 |
| 滞回切换 | edit+3.3 但 F1-7.3 | Pareto 权衡非免费 |
| idle 概率惩罚 | -8.4 | 拆东墙补西墙 |
| 置信度门控合并 | 判别率 0.21 | 真实/噪声段置信度重合 |
| 统一 min_len | -6.7 | 各类段长差 5-10 倍 |
