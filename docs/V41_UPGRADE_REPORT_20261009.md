# v4.1 升级总结：时间轴修正带来全项目最大单次跃升（2026-10-09）

> 本文汇总 v4.1 相较 v3.1 的全部变更与提升，供汇报使用。
> 详细实验记录：[FEATURE_LAB.md](FEATURE_LAB.md) §16；数据集快照：[../datasets/README.md](../datasets/README.md)。

---

## 一句话结论

**发现并修正了 Label Studio 标注时间轴与视频帧率的系统性偏差（24fps vs 30fps），
叠加 15fps 重采样与数据扩量，test edit 从 34.85 提升至 56.46（+21.6，+62%），
withdraw 类 F1 从 0.076 跃升至 0.591（7.8 倍）——此前的 P0 瓶颈被证明主要是标注偏差而非数据不足。**

---

## 一、发现了什么问题（根因）

Label Studio 的标注时间轴按 **24fps** 展开，而实际视频为 **30fps**。这意味着全部标注帧号
相比真实视频帧号存在 **×1.25 的线性漂移**——视频越长漂移越大，结尾处偏差可达 **25% 时长**。

**证据**（无需逐帧核对的数学验证）：14/37 个标注任务的范围上限精确贴住【视频时长 × 24】
（如 #197 时长 111s，标注上限 2664 = 111×24 分毫不差），0 个贴近 30fps——
标注者在 LS 时间轴上标到视频结尾，落点恰是 24fps 换算下的总帧数。

此前所有版本（v1~v3.2）的标签都带着这个偏差训练和评测——模型一直在错位的监督信号上学习。

## 二、v4.1 做了什么（三层变更）

| 变更 | 内容 | 版本 |
|---|---|---|
| **① 时间轴修正** | 全部标签按 LS帧号 × 30/24 重标定（帧级 43.9% 变化、段结构不变，含隔离区） | v3.2（7.5fps 口径）→ v4.0 全量重做 |
| **② 采样率提升** | 7.5fps → **15fps**（stride 4→2），44 个视频全量重检测（yolo11s-g1/g2 同权重） | v4.0 |
| **③ 数据扩量** | #221-238 共 **18 个新视频**入库（14 进 train / 4 进 val） | v4.0 |
| ④ 均衡重划分 | train/val 重划：val 7 视频四类动作均 ≥4 视频覆盖（此前 flush 仅 2、sbc 仅 1 视频覆盖） | v4.1 |

数据规模：train **14 → 28 视频 / 9,646 → 30,930 帧**；val 3 → 7 / 8,447 帧；test 8 不变（5,272 帧）。

## 三、提升了多少（核心数字）

### 3.1 test 基线（nodep-226d + GRU window32，5-seed 中位）

| 指标 | **v4.1** | v3.1 | 提升 |
|---|---:|---:|---:|
| edit | **56.46** | 34.85 | **+21.6** |
| F1@0.1 | **60.16** | 39.18 | **+21.0** |
| F1@0.25 | **48.82** | 31.68 | **+17.1** |

> test 的 8 个视频跨版本未变，为合法同集对比。三项指标相对提升均超 **50%**。

### 3.2 LOVO 交叉验证（35 折稳健估计）

| 口径 | **v4.1** | v3.1（17 折） |
|---|---:|---:|
| edit 中位（raw） | **47.83** | 39.29 |
| edit 中位（+双向时长先验） | **56.25** | 44.44 |
| F1@0.25 中位（+先验） | **50.00** | 26.32 |

### 3.3 逐类 F1（LOVO 合并混淆）——最大亮点

| 动作类 | **v4.1 F1** | v3.1 F1 | 提升 |
|---|---:|---:|---:|
| idle | 0.772 | 0.688 | +0.08 |
| flush | **0.570** | 0.274 | **2.1 倍** |
| long_brush_insert | **0.716** | 0.282 | **2.5 倍** |
| **long_brush_withdraw** | **0.591** | **0.076** | **7.8 倍** |
| short_brush_cleaning | **0.478** | 0.275 | 1.7 倍 |

withdraw 此前 F1 仅 0.076（几乎不可用），被判定为 P0 数据稀缺问题、立项专项采集；
v4.1 后跃升至 0.591——**根因是时间轴漂移**（withdraw 段短且位于动作尾部，受漂移影响最重）。
insert/withdraw 不对称从 3.7 倍收敛到 1.2 倍。

## 四、被改写的结论（重要）

| 原结论 | 修正后 |
|---|---|
| withdraw 是数据稀缺问题，需 action-test 专项采集根治（P0） | **证伪**——主要是标注漂移；专项采集降级为有益补充 |
| 双向先验需条件启用（τ 阈值）避免伤易折 | **不再必要**——漂移修正后预测本身干净，全开即最优 |
| 边界精度（F1@0.25）是长期短板 | 大幅缓解：LOVO F1@0.25 中位 18.18 → 50.00 |

## 五、工程沉淀（长期受益）

| 产出 | 效果 |
|---|---|
