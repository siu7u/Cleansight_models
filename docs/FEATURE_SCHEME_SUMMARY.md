# 特征提取方案评估：结果与结论

> 一句话结论：**在当前数据条件下，只用检测框的空间分布（ROI 网格 144 维）效果最好；
> 引入手部区域编码与通用 CNN 外观特征都未带来增益。** 当前正在做两件事：统一配方后重跑
> 基线以消除口径混杂，并探索 scope 器械轴相对坐标系（clean_bbox_v3）。

## 1. 评测了哪些特征方案（7 种）

同一份检测框数据（YOLO 8 类 `class cx cy w h`），不同的**编码方式**：

| #   | 方案                     | 特征构造                                                   |  维度 | 定位             |
| --- | ---------------------- | ------------------------------------------------------ | --: | -------------- |
| 1   | **bbox-40（基线 B0a）**    | 每类取最大框 → `[presence, cx, cy, w, h]`                    |  40 | 最简基线           |
| 2   | **roi-144（B0b）**       | 画面切 2×3 网格，每 (类, 区域) 统计 `[presence, count, max_area]`  | 144 | **本轮最优**       |
| 3   | **hand-40**            | 只编码"最大 hand 框扩张 1.5 倍"区域内的框，坐标相对该区域归一化                 |  40 | S1 退化组         |
| 4   | **global-hand-80（S1）** | 全局 40 维 ⊕ 手部 40 维                                      |  80 | 方案 1：bbox+手部   |
| 5   | **cnn-120（S2）**        | bbox-40 ⊕ 全帧 resnet18 embedding（PCA-80）                | 120 | 方案 2：bbox+全局视觉 |
| 6   | **hand-cnn-160（S3）**   | 手部 40 ⊕ 全局 bbox 40 ⊕ CNN embedding 80                  | 160 | 方案 3：手部+全局视觉   |
| 7   | **clean_bbox_v3（进行中）** | 以 scope 器械轴建相对坐标系（`control_body → distal_end`），位置/尺度归一 | 113 | 新增探索方向         |

**共同语义**：全部因果、无状态、逐帧独立计算；空帧全零；每一套都是独立 feature_mapping
版本，模型必须重训（不与旧版本混评）。

## 2. 怎么证明结论可靠（受控实验设计）

| 手段 | 做法 |
|---|---|
| **只变一个变量** | 同数据、同模型、同配方、同 seed，**只换特征契约** |
| **数据固定** | `temporal.actionmixed-auto-v3`：train 14 / val 4 视频，12959 标签帧 |
| **模型固定** | GRU（hidden=128，3 层），滑窗时序训练 |
| **配方固定** | weight_decay=1e-4 / dropout=0.2 / patience=4 / best_metric=val_f1_0.5 |
| **多 seed** | 42 / 7 / 2026 三个种子，报**中位数**而非单点（避免抽到好运 seed） |
| **指标口径** | 以**段级** edit score / F1@IoU(0.1/0.25/0.5) 为主——帧级 acc 在 idle 占比 68.2% 的 val 上会被"永远猜 idle"抬到 65%+，**不可用于选型** |
| **诊断佐证** | 逐类 P/R/F1 + 3-seed 合计混淆矩阵 + 训练 loss 曲线（收敛/早停行为） |
| **管线门禁** | 特征预计算链路加入自动校验（逐视频非零占比 ≥99%），防止"静默全零特征"这类假实验 |
| **判据前置** | 新方案必须**同时**优于 bbox-40 与 roi-144 才算增益成立 |

**审计机制发挥了作用**：过程中通过 `status.json` 与 loss 曲线核对，发现三个基线 YAML
缺健康配方（best.pt 按 val_acc 选型、无早停），已定位并修复——这正是"不靠猜、靠证据"
的体现（见 §5）。

## 3. 结果（3-seed 中位数，val）

| 特征方案 | edit ↑ | F1@0.1 ↑ | F1@0.25 ↑ | frame mIoU | 结论 |
|---|---:|---:|---:|---:|---|
| **roi-144** | 24.83 | **24.24** | **18.18** | 11.35 | **本轮最优（暂定）** |
| bbox-40 ⚠️ | 23.35 | 23.66 | 17.20 | **20.93** | 基线（配方混杂，待重跑） |
| hand-cnn-160（S3） | **25.22** | 22.92 | 12.50 | 14.63 | edit 最高但边界精度差，未过判据 |
| global-hand-80（S1） | 18.75 | 21.74 | 13.04 | 17.30 | 未过判据 |
| cnn-120（S2） | 16.01 | 18.37 | 10.42 | 15.28 | 未过判据 |
| hand-40 | 14.56 | 13.79 | 9.20 | 17.62 | 最差 |

⚠️ = 该行产生于口径不一致的配方，需重跑（§5）。

### 3.1 为什么 ROI 网格赢

- 内镜画面中器械位置相对固定，**"哪个类出现在哪个区域"比精确坐标更鲁棒**；
- ROI 丢弃绝对坐标、保留空间分布，天然抑制镜头推拉带来的坐标漂移。

### 3.2 手部方案为何失败（S1）

- 数据事实：scope 类目标在**全画面** presence 为 72~85%，但在**手部区域内仅 14~16%**——
  手部通道把最关键的 scope 信号挡掉了；
- 有趣对照：S3(25.22 edit) ≫ S2(16.01 edit)，说明手部几何信息**确实有正贡献**，
  但以 hand box 区域统计的形式不足以翻案。若重启手部方向，应改用**关键点级特征**
  （MediaPipe 21 点）而非 hand box。

### 3.3 通用 CNN 外观特征为何失败（S2）

- ImageNet resnet18 逐帧 embedding（512 维）→ train 拟合 PCA-80，**EVR 仅 15.6%**；
- 域差距大（自然图像 → 内镜），冻结特征未能提供有效判别信息，反而稀释几何信号；
- 后续若要救这条线：域内微调（linear probe / 末层微调）后再评。

### 3.4 逐类诊断（roi-144，用来说明"难点在哪"）

| 动作类别                 | precision | recall |     F1 | val 帧数 |
| -------------------- | --------: | -----: | -----: | -----: |
| idle                 |    0.6549 | 0.8042 | 0.7219 |   2308 |
| water_injection      |    0.0000 | 0.0000 | 0.0000 |     17 |
| flush                |    0.4179 | 0.0000 | 0.3533 |    183 |
| long_brush_insert    |    0.0413 | 0.0000 | 0.0428 |    495 |
| long_brush_withdraw  |    0.0833 | 0.1019 | 0.1033 |    206 |
| short_brush_cleaning |    0.1739 | 0.0571 | 0.0976 |    175 |

- 整体帧 acc 55.47%、macro F1 0.2029——**非 idle 类召回普遍接近 0**，说明模型定位动作段
  的能力仍是主要瓶颈，段级指标才是主线；
- 数据侧失衡：**idle 占 train 65.52%（6274/9575）、val 68.20%（2308/3384）**；
  water_injection 在 val 仅 17 帧（0.50%），六方案全零命中属数据不足。

### 3.5 训练是否充分？（用 loss 曲线说话，不靠猜）

| 组 | 实际 epochs | train_loss | val_loss 最低点 | 判读 |
|---|---|---|---|---|
| roi-144 / S2 / S3 | 5~6（早停） | 1.2 → 0.70~0.88 | **ep1~2** 后单调恶化 | 训练充分，ep2 起即过拟合 |
| bbox-40 / hand / global-hand | 20（跑满） | 1.4 → 0.23~0.53 | ep3~5 后持续恶化 | 瓶颈同样不在轮数 |

**结论：不存在"训练不足"问题**，瓶颈是泛化（val 分布失衡 + 模型/特征容量 + val 仅 4 视频）。

## 4. 当前结论

1. **特征选型暂定 roi-144（`actionmixed-roi-grid-v1`）**：段级指标全面第一，且因果、无状态、
   纯几何、零额外部署成本；
2. 三个备选方向（手部 box 编码、全局+手部拼接、通用 CNN 外观特征）均**未通过判据**；
3. 手部信息有价值但形式不对 → 未来方向是**关键点级特征**；
4. 尚未定版：需消除配方混杂 + GPU 多 seed 复核。

## 5. 现在在做什么调整（三步）

### 5.1 统一配方、重跑基线（首要）

- **发现**：bbox-40 / hand-40 / global-hand-80 三个基线 YAML 缺健康配方四键，
  best.pt 按 `val_acc` 选型（`status.json` 证实 bbox-40 选中的是 **epoch 1** 的模型）、
  无早停 → 与 roi-144 口径不一致；
- **已修**：补齐 dropout=0.2（model 段）/ weight_decay=1e-4 / patience=4 /
  best_metric=val_f1_0.5，提交 `2d04bf7`；
- **已验证修复生效**：重跑首个 run 使用 val_f1_0.5 选型、按 val_loss 早停于 ep7；
- **状态**：重跑已按需**暂停**（完成 1/9），待后续执行；完成后将替换上表三行。

### 5.2 探索 scope 器械轴相对坐标系（clean_bbox_v3，113 维）

- **动机**：绝对图像坐标在内镜推拉镜头下非平稳；
- **做法**：以 `scope_control_body → scope_distal_end` 定义器械轴，位置编码为沿/垂轴分量
  （÷轴长），面积编码为相对 distal 面积的对数比，含多级回退链；
- **状态**：实现 + 单测（4/4 通过）+ 设计文档 + 契约登记已完成并推送（`bb7d6e9`），
  对照训练配置 `mstcn-clean-v3.yaml` 待跑。

### 5.3 计算口径升级

- 本轮全部为 **CPU/WSL exploratory** 口径、val 仅 4 视频、seed 间方差大
  （bbox-40 的 edit 从 17.0 到 25.4）；
- 定版前需在有 GPU 的机器上做**多 seed 正式复跑**，并按 benchmark 规范挂固定 testset。

## 6. 局限与风险（如实说明）

1. val 仅 4 个视频，逐类数字（尤其 water_injection）统计意义有限，**不做单类结论**；
2. 三个基线数字受配方混杂影响，**重跑前不可用于定版**；
3. PCA-80 的 EVR 仅 15.6%，CNN 线若重启应换投影维度或做域内微调；
4. 所有结论目前均为 exploratory 口径，正式结论需 GPU 复跑背书。
