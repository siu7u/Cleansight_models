## 4. 未验证 / 未覆盖清单（不得当作已复现引用）

| 项 | 缺什么 |
|---|---|
| `TOPIC_03_04` §3.9(B) 源域 30 折 × 契约的精确值 | 算力：HistGB 单折 ~52s 且必须 `OMP_NUM_THREADS=1`，120 折 ≈1.7h（本轮只做了降级 8 折） |
| `confcurve` 的精度列 | 产物 JSON 不落"检测总数"，无法核对 |
| flush 归零的**归因**（两个候选契约解释） | 需新建中间契约 + 32 seed 重训（GPU） |
| 架构网格未覆盖的搜索空间 | transformer 的 warmup×wd×层数**联合**、fact 的 token 数/匹配权重、预训练/迁移路线 |
| "换特征契约后架构排序是否翻转" | 本轮全部锁在 v4 |
| 目标批次视频级 k 折重训 | 需用户批准改动 `testsets.yaml` 的 split 登记 |
| 上线延迟/吞吐 | 由 `CleanSightBackend` 拥有；本仓库只产出模型与评估事实 |
