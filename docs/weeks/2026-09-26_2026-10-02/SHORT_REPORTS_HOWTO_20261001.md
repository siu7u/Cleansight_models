# 怎么做简短报告（2026-10-02）

> 起因：本周素材已到 14 份文档 / 5,000+ 行，而日常要发的是**三五行的数字**。
> 本文件给一套可复用的做法：**三条纪律 + 三种长度 + 一条取数命令 + 本周可直接发的实例**。

## 0. 一句话

短报告不是"把长文档删短"，而是**换组织单位**：
长文档按**证据**组织（我做了什么、怎么证明的），短报告按**对方要做的决定**组织（所以你要拍什么板）。
删减只会得到一份残缺的长文档。

## 1. 三条纪律

1. **结论先行**：第一句就放数字，不写"本周我们围绕……开展了……"。
2. **数字必须带三件套**：口径（哪个指标 / 哪个协议）、样本量（几个 seed）、**统计层级**
   （seed 级还是视频级——本周实测两者 p 值差 3~4 个数量级）。
3. **每篇只留一个待决策项**。列三个"待拍板"，等于告诉对方"都不急"。
4. **附一行"没做什么 / 被什么否掉了"**：排除清单的信息量最大，
   也是防"那你们怎么不试试 X"的唯一有效手段。

## 2. 三种长度（挑一个写，不要都写）

| 长度 | 用在哪 | 预算 | 骨架 |
|---|---|---|---|
| **3 行** | 站会口播、群里同步 | ≤120 字 | 数字 + 取舍 + 待决策 |
| **半页** | 周报邮件 | ~300 字 | 3 行版 + 排除清单 + 下一步 3 条 |
| **一页** | 月度/评审 | ~600 字 | 见 [`WEEKLY_ONEPAGER_20261001.md`](WEEKLY_ONEPAGER_20261001.md) |

## 4. 数字从哪来：一条命令，**不要手抄**

手抄的数字会过期——本周数据版本换成 v3.1 后，所有绝对读数都变了。
取数用 `tools/week_digest.py`（统计口径复用 `tools/compare_runs.py`，不新增口径）：

```bash
PY=/home/caizh/programming/python_code/CleanSightBackend/.venv/bin/python

# 三行版（默认模板里最省的那一档）
$PY tools/week_digest.py \
  --baseline "roi-grid-v1=runs/gpu-batch/recheck-flagship/h128/mstcn2-*,runs/acc-push/acc-roiv1-seedB/h128/mstcn2-*,runs/acc-push/acc-roiv1-seedC/h128/mstcn2-*" \
  --arm "roi-grid-v4=runs/acc-push/acc-roiv4/h128/mstcn2-*,runs/acc-push/acc-roiv4-seedB/h128/mstcn2-*,runs/acc-push/acc-roiv4-seedC/h128/mstcn2-*" \
  --style brief

# 半页版（+ 中位数表 + seed 级/视频级两张配对表）；--style page 再加逐类与段结构
# 换数据版本只需换 glob：runs/v31/roiv{1,4}{,-b}/h128/mstcn2-*
```

输出示例（2026-10-02 实跑，与剖析文档逐位一致）：

```
**roi-grid-v4 vs roi-grid-v1**：acc 中位 53.90 → 58.31（**seed 级**配对 Δ 中位 **+4.47pp**，胜/负 32/0，p=7.9e-07，n=32）
段级：edit Δ 中位 **-8.32pp**（7/25，p=4.4e-05）
来源：基线 roi-grid-v1 32 run；臂 roi-grid-v4 32；口径=官方评测产物 seed 中位 + 逐 (seed,视频)×类配对
```

**为什么要工具**：它把"配对层级"和"样本量"强制写进输出里——这两项恰是本周最容易出错的地方
（`acc` 在产物里没有逐视频记录，只能在 seed 级配对；写成视频级 p 值会把证据强度夸大约 3 个数量级）。

## 5. 五个常见坑（本周都踩过或差点踩）

| 坑 | 后果 | 防法 |
|---|---|---|
| 手抄数字 | 数据版本一变，短报告就成了错误报告 | 一律跑第 4 节的命令 |
| 混用协议 | "59.30 − 53.92 = +5.38pp" 是错的（两套协议相减） | 报"提升"必须两臂同协议重算基线 |
| 把 seed 级 p 当视频级 | 证据强度夸大 3~4 个数量级（7.9e-07 vs 0.008~0.070） | 输出里强制标注层级（工具已内置） |
| 把单点探索当结论 | 单 seed 的镜像对照可差 ±2pp | 8 seed 判 ~1.9pp、16 seed ~1.35pp、32 seed ~0.95pp |
| 只报涨不报跌 | `acc` +4.47 的背后是 `edit` −8.32 与 `flush` 归零 | 每篇至少带一个段级指标 |
