## 1. 背景（为什么先做这两件事）

上周 v4.1 全量重训给出两个必须回应的读数：

1. **契约排名不迁移**（新旧尺子 Spearman ρ=−0.149）：v3 冠军 `roi-v4` 在 v4.1 上垫底（64.91），
   而 `bbox-global-hand`（80 维，acc 76.27）与 `roi-v5`（192 维，edit 69.43）分列两项指标之首
   —— **没有一个契约全能**；
2. **`val_edit` 选点在部分臂上反噬**（transformer best 比 last 低 17.12pp）。

于是本周排了四件**低成本、可立即证伪**的事：**① 把多个模型投到一起有没有用（协议层）；
② 把两个最强的契约拼进一个模型有没有用（模型层）；③ 15fps 之后在线轨的窗口是否该加倍
（超参层）；④ 这批候选在两个 split 上是否同向（口径层，通过把 11 个臂全部在 val 上复评来执行）。**

### 2.2 四条要点

1. **多成员投票是 `acc` 的有效杠杆，而且 val 比 test 更支持它**
   （同契约 8-seed：val **11/11** 臂为正、中位 **+2.27**；test 9/11、中位 +1.50）。
   `edit` 只是"中位为正"（test 7/11、+0.40；val 7/11、+3.32），**同一臂两 split 常一正一负**，
   与噪声不可分。代价是推理要跑 8 个成员（离线全序列可接受，在线不可）。
2. **`edit` 的漂亮读数全是 test 口径或 test 选点**：跨契约投票在 val 上 edit 显著为负
   （−3.02，加最小时长合并后仍 −1.21），55 个组合的 val↔test 排名几乎不相关
   （ρ=+0.058 acc / +0.121 edit）→ 不能"用 val 挑最好的一对"，按 test 挑则是选点泄漏。
   **本仓库既有的"test 涨、val 不支持不计交付"纪律再次生效。**
3. **拼接（组合契约）在 v4.1 上依然没有可测协同**：`combo-v2` 落在两个父契约之间
   （vs `roi-v5` acc +0.81 / edit −0.78，不可分；vs `global-hand` edit +7.69 但 acc −0.93）。
   与 v3 时代 combo-v1 的结论同型——**拼接换到的是"段结构 + 稀类召回"，不是"帧判对率"**。
4. **在线轨的差距不是窗口长度造成的**：`window:16`(1.07 s) → `32`(2.13 s) 8 seed 配对下
   acc **−2.61**、edit +0.79（段级不可分）→ 15fps 换算出来的"感受野物理时长减半"这条
   直觉性假设**被实测否定**，在线轨（58.8）与离线轨（74.5~76.3）之间 16~17pp 的差距要另找原因
   （因果约束 / 逐窗口末态决策 / 样本构造）。
5. **（10-11 上午）手部区域的锚点是一条真杠杆**：把区域从"面积最大的单个 hand 框"改成
   "**全部 hand 框的并集**"，`bbox-global-hand` 只改这一处（16 seed）即拿
   **test acc 76.27 → 79.15（+2.88）、edit 64.14 → 66.37（+2.23）**，
   **val acc 72.36 → 75.17（+2.81）、edit 72.29 → 75.14（+2.85）**；
   test 段级 f1@0.1/0.25/0.5 的配对 p 分别为 **0.017 / 0.011 / 0.0006**。
   40 维的 `bbox-hand-v2` 同向（test acc 75.98 → 77.75、edit 62.44 → 66.35；
   **val acc 68.26 → 77.75，全仓库最高**）。
   **这是本周唯一"两个 split × 两个指标"同时改善的单模型改动**，来源是一条从未被调过的
   recipe 常数（锚点规则 + `HAND_REGION_EXPAND`），而不是新架构或新数据。
   机制上：并集区域让左右手同时入镜、器械在手间传递时区域不再跳 → 预测段数比 **1.10 → 0.95**，
   `flush` 召回 30.1 → 52.5、`withdraw` 61.1 → 67.9、`insert` 83.1 → 86.4（`hand-v2`）；
   代价是 `sbc` 仍恒 0（该证据不在手部区域内）。
   叠加同契约 8-seed 投票后 `global-hand-v2` 在 **test acc 80.50 / edit 71.24**、
   **val acc 76.59 / edit 77.81**（四个格子全为正）。
