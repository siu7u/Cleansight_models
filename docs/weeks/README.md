# 周工作目录（`docs/weeks/`）

> **约定（2026-09-28 起生效）**：每一周的工作在 `docs/weeks/` 下**建一个文件夹**，
> 该周产生的过程性文档、简报与实验记录都放在里面。
> 本约定同时写入项目 skill：`.dsh/skills/modelset-quality/SKILL.md`。

## 1. 周的划分与命名

- **一周 = 周六 ~ 次周五**（不是自然周 Monday–Sunday）。
- 文件夹名 = `<起始周六>_<结束周五>`，格式 `YYYY-MM-DD_YYYY-MM-DD`，可直接按名称排序。
  - 例：`2026-09-26_2026-10-02`（2026-09-26 是周六，2026-10-02 是次周五）。
- 建新周文件夹前先用 `date` 确认当天落在哪一周，不要凭推算：
  ```bash
  date "+%Y-%m-%d %A"                 # 今天是星期几
  date -d "last saturday" +%Y-%m-%d   # 本周起始周六（若今天就是周六则为今天）
  date -d "friday" +%Y-%m-%d          # 本周结束周五（周六/周日执行时指上一周，需自行判断）
  ```

## 2. 文件夹里放什么

| 文件 | 作用 | 维护方式 |
|---|---|---|
| `README.md` | **本周简报**：本周结论、改了什么、遗留与下周计划 | **即时更新**——每完成一项工作就追加，不要攒到最后 |
| 主题文档 | 该周新增的过程性文档（实验设计、机制说明、探针结果等） | 每份文档在简报里登记一行 |

**判定一条内容该不该进周文件夹**：看它的生命周期。

- **生命周期 ≤ 一周**（过程记录、当日结论、调试笔记）→ 放周文件夹。
- **长期有效、会被跨周引用**（实验报告 `EXPERIMENT_REPORT_*.md`、指标口径
  [`../EVAL.md`](../EVAL.md)、模型总览 [`../MODELSET_OVERVIEW.md`](../MODELSET_OVERVIEW.md)）
  → 仍放 `docs/` 根或既有位置，**由周简报索引**，避免跨周链接失效。

> 约定建立（2026-09-28）之前产生的文档保留原位，不回填；本周简报中已登记索引。
